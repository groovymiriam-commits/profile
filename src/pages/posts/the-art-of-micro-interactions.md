A button changes color when it is pressed. A form explains what needs fixing. A menu makes it clear that it opened. These small moments are easy to overlook, but they help people understand how an interface responds.

## A small signal, not a small spectacle

A micro-interaction works best when it connects an action to an outcome. A subtle change in a saved icon can confirm that an item was saved. A loading indicator can show that a request is still underway. The response should be noticeable enough to help and quiet enough not to interrupt.

When an effect does not add feedback, clarity, or a little bit of character, it may not need to be there.

## Design the whole moment

Think about a micro-interaction in four parts:

1. **The trigger:** what the person does, such as clicking, typing, or focusing.
2. **The response:** what changes in the interface.
3. **The feedback:** what confirms the result or explains a problem.
4. **The repeat:** what happens when the action occurs again or is undone.

Considering the full moment catches awkward gaps. For instance, a save control needs a clear saved state and a way to change that state again.

## Make the response work without motion

Animation can reinforce feedback, but it should not be the only way to receive it. Pair motion with a visible state change, useful text, and appropriate semantics. Make sure the control remains understandable to keyboard users and people using assistive technology.

## Consistency makes the details feel intentional

Use similar timing and visual language for similar actions. If one confirmation is immediate and another arrives after a long animation, the interface can feel unpredictable. A small set of consistent patterns makes the experience easier to learn—and leaves room for a little personality where it counts.
